# Style collections

Read [general schematic preferences](../preferences/GENERAL.md) first, then the relevant `STYLE.md`, its available domain guides, and examples selected by the illustration feature needed. Styles inherit shared preferences unless they declare an explicit exception. Do not read the entire library on every task.

For visual browsing, open [The Art of Electronics showcase](THE_ART_OF_ELECTRONICS/README.md) or [all examples by category](THE_ART_OF_ELECTRONICS/examples/README.md).

| Collection | Use for | Current state |
| --- | --- | --- |
| [The Art of Electronics](THE_ART_OF_ELECTRONICS/STYLE.md) | [Schematics](THE_ART_OF_ELECTRONICS/SCHEMATICS.md) and [qualitative plots/signals](THE_ART_OF_ELECTRONICS/PLOTS.md), including combined figures | Collecting; thirty-one reference records: five with LaTeX/SVG/PNG and gallery pages, twenty-six without saved images; original-image references supported, two imports blocked; shared patterns provisional |

To start, resume, add examples, or preserve a useful generated result, use the [collection workflow](../skills/schematica-examples/SKILL.md). New sources receive their own collections under `styles/`; the workflow is shared. Each collection can support several separately selectable domains. Create only guides and example categories with actual content; a planned domain is not an implemented style.
