# Symbol library

Browse six electronic symbols, choose size and stroke independently, and download
one SVG or a six-symbol Inkscape library. Dark and light themes are included.

- [Open the web preview](https://schematica-preview.dinodubroja.workers.dev/)
- [Review this implementation: changes, test steps and results](CHECKPOINT.md)
- [Run, build and test on Windows](DEVELOPMENT.md)
- [Use exports in Inkscape](INKSCAPE.md)
- [Rendering proof](review/library-proof.png)
- [Portable website ZIP](review/web-preview.zip)

From this folder, run `./launch.ps1` to open the local preview. First-time setup is
in the development guide. The shared preview opens on either Windows device without
installing the repository or Python.

This is a read-only library browser. Creation, personal variants, schematic styles
and circuit comparisons are future work. The shipped library will remain separate
from user-created content.
